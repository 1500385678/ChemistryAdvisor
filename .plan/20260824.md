## 解析器设计要点

1. **frontmatter 解析**:每个 md 头部有 5 个标准字段(`类型` / `适用角色` / `关联技能` / `更新日期` / `来源`),用 `re` 抽出来
2. **标题层级**:`##` 章节列表 / `###` 小节 / 标题正文,支持嵌套
3. **表格解析**:`|` 分隔,首行为表头,产出 `{headers, rows}`
4. **引用/加粗**:`>` 引用块保留;`**xx**` 转 markdown 字段
5. **JSON Schema**:`{name, type, role, skills, updated, source, sections: [{title, level, content, tables}]}`
